# RAG Architecture

Knowledge preserves ID, source, authority, and text. Authority order is safety architecture (100), explicit Terri rules (95), program rules (90), program metadata (85), approved Boost metadata (80), official website (70), transcripts (50), and model inference (0).

The initial small corpus uses local lexical retrieval. `EmbeddingProvider` isolates Google embeddings for indexed retrieval. Similarity may rank knowledge or already-eligible content; it never decides safety or eligibility. Static embeddings must be cached.
