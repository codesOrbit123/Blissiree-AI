# AI Training Studio

The Training Studio is the governed behavioural memory of Emma and Ben. “Training” means managing the layered Blissiree configuration—not silently uploading text to Gemini or changing foundation-model weights.

## Areas

- **Train AI:** creates structured, attributable instructions for All AI, Emma, or Ben. Validation previews conflicts, affected components, expected impact, and proposed regression requirements before activation.
- **Training Library:** exposes migrated runtime instructions, protected safety rules, document knowledge, program content, all 61 Boost collections, and all 191 audio catalogue records. Items are searchable and traceable by source, target, category, priority, authority, version, dependencies, and tests.
- **Training History:** records immutable Blissiree AI configuration builds and regression results.

## Governance

Protected critical items cannot be archived or deleted. Active changes preserve a prior snapshot in item history. Disabling is preferred to removal. Lower-authority items cannot silently replace protected Terri/safety rules; candidate conflicts block activation. Admin APIs require a secret access key and store library data in the private GCS configuration object.

## Compilation

The runtime compiler selects only active shared and selected-persona behavioural instructions. Knowledge remains retrieval-driven and content remains separate from behavioural rules. An AI rebuild validates the active library, refreshes effective persona configuration, runs the registered regression suite, and creates a new version record.
