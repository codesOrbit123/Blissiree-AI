# Long-Term Journey Engine

Long-term routing is conservative and uses current program status, completed sessions, longitudinal patterns, recovery-stage confidence, readiness, engagement, and user goals. One difficult day cannot change recovery stage or trigger a Program.

Emotional Empowerment is the foundational journey. Unstoppable You is considered only for sufficiently stable, growth-ready users under Terri's rules. Existing sequential progress takes priority over content similarity.
