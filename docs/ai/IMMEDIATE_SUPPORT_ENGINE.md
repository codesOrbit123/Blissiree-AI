# Immediate Support Engine

The engine answers: “What approved Blissiree support may fit right now?”

1. Run deterministic triage.
2. Block content for T0–T4 and other architecture-defined crisis states.
3. Extract only explicitly reported, non-diagnostic current-state observations.
4. Determine one dominant immediate need.
5. Filter to active, reviewed, approved, age-appropriate, stage-eligible Boosts.
6. Apply avoid rules and safety flags before ranking.
7. Normally return one smallest-useful Boost with an auditable reason.

The 61 supplied Boost collection mappings are approved as the collection-level routing vocabulary. The engine may recommend a current collection name using deterministic need rules. Individual audio recommendation remains blocked until verified audio-to-collection membership and eligibility metadata are populated.
