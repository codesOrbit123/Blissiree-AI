# Safety Architecture

`TriageEngine` combines deterministic patterns, structured signals, explicit input, and stress thresholds. T0–T5 block recommendations. T6 permits moderate-distress support and T7 stable support.

Gemini is not the safety authority. If analysis fails, deterministic rules still run. If generation or validation fails, the backend returns a deterministic fallback. Blissiree never diagnoses, treats, prescribes, stores medical records, or presents itself as emergency support.
